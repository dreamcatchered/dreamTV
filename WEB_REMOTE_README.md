# 📱 Веб-пульт DreamTV — Управление ТВ со смартфона

## 🎯 Описание

Это официальный веб-пульт для приложения **DreamTV**, который позволяет управлять телевизионной приставкой **со смартфона или планшета** прямо из браузера. Оба устройства должны быть **в одной сети (Wi-Fi)**.

### ✨ Возможности

- 📺 **Просмотр всех каналов** с логотипами и красивой сеткой
- 🔍 **Мгновенный поиск** по названию канала
- ⏯️ **Полное управление**: play, pause, next, previous
- 🔊 **Контроль громкости** из браузера
- 🎬 **Переключение каналов** в один клик
- 📊 **Real-time синхронизация** состояния приставки (WebSocket)
- 🌙 **Красивый тёмный дизайн** с градиентами
- 📱 **Адаптивный интерфейс** для мобильных, планшетов и ПК
- 🔗 **Локальный доступ** — без интернета, работает только в сети

---

## 🚀 Как использовать

### 1️⃣ Включить веб-пульт в приложении

1. Откройте **DreamTV** на приставке
2. Перейдите в **Настройки** (последняя вкладка)
3. Найдите опцию **"Веб-пульт 📱"**
4. **Включите** тумблер
5. Нажмите кнопку **"📲 Показать QR-код пульта"**

### 2️⃣ Подключиться с телефона

#### Способ А: Через QR-код (Быстро ✨)
- Откройте камеру вашего смартфона или приложение для сканирования QR
- **Отсканируйте QR-код**, который показывает приставка
- Вы будете автоматически перенаправлены на веб-пульт

#### Способ Б: Ручной ввод URL (Если QR не сканируется)
- На приставке найдите **локальный адрес** (например: `http://192.168.1.100:8080`)
- Откройте этот адрес в браузере своего смартфона
- Готово!

### 3️⃣ Управление

| Функция | Как использовать |
|---------|-----------------|
| **Переключение канала** | Нажмите на нужный канал в сетке |
| **Поиск** | Введите название канала в строку поиска |
| **Play/Pause** | Кнопки управления воспроизведением |
| **Следующий/Предыдущий** | Кнопки "Далее" / "Пред." |
| **Громкость** | Передвигайте ползунок громкости |

## 🔧 Технические детали

### Архитектура

- **Backend**: Kotlin (Ktor HTTP Server, WebSockets)
- **Port**: `8080`
- **Protocol**: HTTP + WebSocket
- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Autoupdate**: Real-time синхронизация через WebSocket

### REST API Endpoints

```
GET  /api/status              - Текущее состояние плеера
GET  /api/channels            - Список всех каналов
GET  /api/qrcode              - QR-код и локальный адрес
POST /api/channel/{id}        - Переключиться на канал
POST /api/command             - Отправить команду (play, pause, etc)
WS   /ws/remote               - WebSocket для real-time обновлений
```

### Команды API

```json
// Переключить канал
POST /api/command
{"command": "switchChannel", "value": 0}

// Play/Pause/Next/Prev
POST /api/command
{"command": "play"}
{"command": "pause"}
{"command": "next"}
{"command": "prev"}

// Громкость
POST /api/command
{"command": "setVolume", "value": 50}
```

## ❓ FAQ

### Q: Требуется ли интернет?
**A:** Нет! Пульт работает **только в локальной сети**. Интернет не требуется.

### Q: Работает ли с мобильной сетью (4G/5G)?
**A:** Нет, оба устройства должны быть в **одной Wi-Fi сети**.

### Q: Можно ли управлять несколькими приставками?
**A:** Да! Каждая приставка на порту 8080 может быть отдельным пультом. Просто подключитесь к разным IP-адресам.

### Q: Как узнать IP адрес приставки?
**A:**
- Посмотрите в **Настройки → Веб-пульт → Показать QR-код**
- Там будет указан локальный адрес
- Или найдите в настройках роутера

### Q: Почему пульт не подключается?
**Проверьте:**
1. Оба устройства в **одной Wi-Fi сети**
2. Приставка включена и **веб-пульт включен в настройках**
3. Порт 8080 не забит файерволлом
4. IP адрес правильный

### Q: Почему каналы не загружаются?
**A:** Убедитесь, что плейлист загружен в приложении DreamTV перед открытием пульта.

## 🛠️ Для разработчиков

### Локальное тестирование

```bash
# Запустить Gradle build
./gradlew build

# Запустить на эмуляторе/устройстве
./gradlew installDebug
```

### Отладка WebSocket

Откройте DevTools браузера (F12) → Console:
```javascript
// Отправить команду вручную
ws.send(JSON.stringify({command: "next"}))
```

### Расширение функционала

Добавьте новые команды в `WebRemoteService.kt`:

```kotlin
WebRemoteService.commandCallback = { cmd ->
    when (cmd.command) {
        "myNewCommand" -> { /* ваш код */ }
        else -> {}
    }
}
```
